# Field Notes Portfolio

Create an interactive landing page using only the supplied images. Do not add any extra images, extra objects, or redesign the visual identity.

Use the supplied drafting-grid / site-plan image as the full-page background. It should fill the entire scene and remain subtle, acting as a technical architectural backdrop. Keep the background light, clean, and mostly flat so the foreground elements stand out.

Place the supplied “KIRAN’S DIGITAL FIELDNOTES” logo near the upper center of the page as the main title element. Preserve its exact graphic feel, including the bold black text and pink cursor. Do not restyle it.

Use only the two supplied architectural project images as the main featured visual elements:

 Place the colorful architectural render toward the lower-left to lower-middle area.

 Place the curved snowy building render toward the middle-right area.
Keep them floating like collage elements over the drafting background, with generous white space around them. Do not place them inside generic website cards or frames.

Place the navigation items vertically in the bottom-left corner using the supplied button images in this order:
CV
WRITING
INTERIORS
OBJECT
ARCHIVES

Each navigation item should remain visually simple and aligned like an editorial/architectural portfolio index. Keep the overall page composition minimal, spacious, and visually similar to an architecture presentation sheet.

Interactions

All project images and all navigation buttons should be interactive.

Hover interaction for project images

When hovering over either project image:

 slightly raise the image upward

 move it slightly toward the viewer

 scale it up subtly, around 1.03 to 1.06

 add a soft shadow to create elevation

 optionally add a very slight tilt, no more than 1 to 2 degrees

 animate smoothly over about 250 to 350 milliseconds

When hover ends, the image should smoothly return to its original position.

Hover interaction for navigation buttons

When hovering over any button:

 slightly raise it upward

 add a subtle shadow or sense of elevation

 slightly scale it up, very subtly

 keep the movement minimal and clean

 animate smoothly over about 200 to 300 milliseconds

All buttons should be clickable, but for now they should not navigate anywhere or trigger page changes.

General motion

Add a very subtle mouse-responsive parallax effect so the two project images feel lightly suspended above the background. Keep this restrained and elegant. The title/logo may have a tiny amount of parallax as well, but less than the project images.

The page should feel like an architectural portfolio sheet brought to life, not a corporate website. Maintain a raw, clean, editorial, architecture-student aesthetic.

Important constraints

 Use only the supplied images

 Do not add extra thumbnails, icons, photos, people, or decorative objects

 Do not introduce rounded modern SaaS cards, neon effects, glassmorphism, or unrelated 3D decoration

 Keep the layout minimal, spacious, and collage-like

 Preserve the theme and visual language of the supplied assets

The final result should be a polished, interactive main landing page for an architecture portfolio, with hover elevation on both the project images and the navigation buttons.
